LinuxCTS 综合测试脚本

推荐

系统信息、性能测试、网络检测、服务状态检查以及常用安装脚本合集。既支持临时运行，也可以安装到系统里长期使用。

方式一 · 一键运行（临时使用，不落盘）

linux.sh 
source <(curl -sL https://linuxcts.itgpt.top/linux.sh)

方式二 · 安装到系统

linux.sh 
sudo curl -L https://linuxcts.itgpt.top/linux.sh -o /usr/bin/linux && sudo chmod +x /usr/bin/linux

安装完成后，在终端输入 linux 即可打开功能菜单；需要更新时重新执行上面这条命令覆盖即可。

卸载

terminal 
sudo rm -rf /usr/bin/linux
